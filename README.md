# Bhavcopy Processor

A fast, free **Windows desktop application** to download and process official **NSE Bhavcopy** data — Equity, Index & Futures. No scripts, no Python, no manual work required.

🌐 **Website:** https://matrixvipin.github.io/BhavcopyProcessor-Website/

---

## ✨ Features

- **NSE Equity & Index data** — Downloads and processes official NSE Equity Bhavcopy and Index closing files
- **Futures (F&O) data** — Full support for NSE Futures Bhavcopy ZIP files
- **Date-range processing** — Bulk download any historical date range in one click
- **Automatic daily downloads** — Built-in Windows Task Scheduler integration for hands-free daily updates
- **Smart date detection** — Automatically detects the latest available trading day and skips already-processed dates
- **Built-in update checker** — In-app "Check for Updates" with one-click download & install
- **Local & private** — All data stays on your PC; nothing is sent to third-party servers

## 🎯 Use Cases

- **Traders & Investors** — Get clean, ready-to-use daily NSE Equity/Futures data for analysis without writing scripts
- **Algo & Quant Developers** — Feed processed CSV data directly into your backtesting or strategy tools
- **Data Analysts** — Bulk-download historical date ranges for research and reporting
- **Educators & Students** — Learn market data workflows with a simple, no-code tool
- **Anyone tracking NSE markets** — Automate daily EOD data collection with the built-in scheduler

## 🚀 How It Works

1. **Select date range** — The app auto-detects the latest available trading day
2. **Choose data types** — Toggle NSE Equity and/or NSE Futures
3. **Click Download & Process** — Files are downloaded from NSE and processed into clean CSVs
4. **(Optional) Enable Scheduler** — Automatic daily download at your preferred time
