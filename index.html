What is Bhavcopy Processor?

Bhavcopy Processor is a free Windows desktop application that downloads the official National Stock Exchange (NSE) Bhavcopy files and converts their CSV and ZIP end-of-day (EOD) data into clean .txt files ready for EOD charting and analysis applications such as AmiBroker, AdvancedGET EOD and similar tools. It handles NSE Equity, Index, Futures and Index Futures — automatically, with no Python, no scripts and no technical setup.

Note: Bhavcopy Processor works with daily end-of-day (EOD) files only — it does not process intraday or tick data.

Why use Bhavcopy Processor?

  • Ready for EOD software — Converts CSV/ZIP bhavcopy files into .txt format that you can import directly into AmiBroker, AdvancedGET EOD and similar applications.
  • NSE Equity & Index — Full support for NSE Equity bhavcopy and Index closing (EOD) files.
  • NSE Futures & Index Futures — Processes NSE Futures bhavcopy files, including Index Futures EOD data.
  • End-of-day only & easy to use — Handles daily EOD data with a simple point-and-click interface; no scripts or coding.
  • Bulk historical date ranges — Download any trading date range in one click for research and backtesting.
  • Automatic daily scheduler — Built-in Windows Task Scheduler integration for hands-free end-of-day updates.
  • Smart date detection — Automatically finds the latest available trading day and skips already-processed dates.
  • Local & private — All data stays on your PC; nothing is uploaded or shared.

How it works

  1. Select the date range — the app auto-detects the latest available trading day.
  2. Choose the data types — toggle NSE Equity / Index, and/or NSE Futures / Index Futures.
  3. Click Download & Process — EOD files are fetched from NSE, unzipped and parsed.
  4. Use the output — the parsed EOD data is saved as .txt files ready for AmiBroker, AdvancedGET EOD and other applications.
  5. (Optional) Enable the Scheduler — automatic daily download at your preferred time.

Frequently asked questions

Is Bhavcopy Processor really free?

Yes. Bhavcopy Processor is free to download and use, with no hidden costs, subscriptions or paid tiers.

What is a Bhavcopy file?

A Bhavcopy is the end-of-day (EOD) file published by NSE containing the day's trading summary — open, high, low, close, volume and more — for all traded securities and index/futures contracts.

Does it do intraday or tick data?

No. Bhavcopy Processor is built specifically for daily end-of-day (EOD) bhavcopy files. It does not process intraday, tick or minute-level data.

What output format does it produce?

Bhavcopy Processor converts the NSE CSV and ZIP bhavcopy files into .txt format, ready to import into EOD charting and analysis applications such as AmiBroker, AdvancedGET EOD and others.

Which markets and products are covered?

The app supports NSE Equity, NSE Index closing files, NSE Futures and NSE Index Futures EOD data.

Do I need Python or other tools?

No. Bhavcopy Processor is a standalone Windows application. Everything (download, unzip, parse and .txt export) is handled inside the app.

Which versions of Windows are supported?

Bhavcopy Processor supports Windows 10 and Windows 11, in both 64-bit (x64) and 32-bit (x86 / ia32) editions.
